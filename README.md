# 🚀 Fluor (Аналог Reddit)

Веб-приложение, повторяющее основной функционал популярной платформы Reddit. Пользователи могут регистрироваться, создавать посты, просматривать ленту и управлять своим профилем. Проект находится в активной стадии разработки, текущие задачи декомпозированы в Jira.

## 📌 О проекте

Цель проекта — создать интуитивно понятный интерфейс и надёжный бэкенд для публикации и обсуждения контента. Основное внимание уделяется качественной вёрстке, удобной навигации и проработанному дизайну всех ключевых страниц.

## ✨ Ключевой функционал

В соответствии с текущими задачами, приложение будет включать следующие модули:

### 🔐 Аутентификация и авторизация
- Разработка страницы регистрации и входа
- Создание уникального дизайна страницы регистрации

### 📰 Лента
- Создание страницы с основной лентой постов
- Разработка дизайна и адаптивной вёрстки страницы "Ленты"

### 📝 Посты
- Создание страницы для просмотра и создания отдельного поста
- Проектирование дизайна страницы поста

### 👤 Профиль пользователя
- Создание страницы личного профиля
- Разработка дизайна страницы профиля 

### 🎨 UI/UX и общие компоненты
- Формирование единых общих стилей проекта 
- Добавление навигационной панели для удобного перемещения по приложению
